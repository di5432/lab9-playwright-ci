# lab9-playwright-ci
Laboratory work 9 - GitHub Actions CI
## Самостоятельное задание

В рамках лабораторной работы настроен CI/CD с использованием GitHub Actions.

Выполнено:
- Автоматический запуск UI-тестов Playwright.
- Проверка работы приложения.
- Сохранение результатов тестирования.
- Проверка выполнения тестов при изменении кода.
